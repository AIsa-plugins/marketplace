# Privacy Policy

## Data processed

AIsa Search processes the search queries, public web URLs, and search options
that a user or a Dify application supplies to a tool. User-provided text may
contain personal data, so users should avoid submitting sensitive information
that is not necessary for their research request.

The plugin also uses an AIsa API key supplied through Dify's encrypted provider
credential interface. The plugin does not include that key in tool output.

## Use and transmission

Tool inputs and the AIsa API key are transmitted over HTTPS to the AIsa API at
`https://api.aisa.one` solely to perform the requested operation. Depending on
the selected tool, AIsa may use web search, X/Twitter, YouTube, and scholarly
search providers to retrieve results. See the [AIsa Privacy
Policy](https://aisa.one/privacy) for AIsa's current processing, subprocessors,
and retention practices.

The plugin itself does not use Dify persistent storage, advertising trackers,
or analytics, and does not intentionally create a separate copy of tool inputs
or results. Dify workspace logs and AIsa services may retain request data under
their respective administrators' settings and policies.

## User choices and deletion

Users can stop further processing by removing the plugin or its provider
credentials from their Dify workspace. Requests concerning data handled by
AIsa may be submitted through the contact method in the AIsa Privacy Policy.
Questions about copies held in Dify logs should be directed to the applicable
Dify workspace administrator.

## Contact

Privacy questions may be sent to developer@aisa.one.
